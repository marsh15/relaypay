# Upgrade to RelayPay v0.6.0

Back up the v0.5 databases and stop API/workers. Provision the separate `commerce` database with
distinct app and migrator credentials, then run:

```bash
make migrate
uv run alembic -c migrations/relaypay/alembic.ini check
uv run alembic -c migrations/commerce/alembic.ini check
```

Migration `0011_connectors` creates empty connector, encrypted credential, health, inbound event,
and processing-attempt tables. It does not rewrite existing payment, payout, journal, event, or
provider evidence. The independent commerce migration creates empty account, order, and payment
link tables.

Configure `CONNECTOR_CREDENTIAL_ENCRYPTION_KEY`, `COMMERCE_DATABASE_URL`,
`COMMERCE_CONTROL_SECRET`, and the commerce account identifier before seeding.

Do not downgrade after connector credentials or inbound evidence exist. Restore the pre-upgrade
backup instead. Downgrade is only for a disposable empty sandbox.
