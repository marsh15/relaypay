# Migrating to RelayPay v0.9.0

v0.9.0 adds an operations-console read surface and requires no database migration.

1. Upgrade from the exact green `v0.8.0` tag.
2. Keep the existing RelayPay, provider, receiver, bank, commerce, Redis, and session settings.
3. Build the console and API images from the same v0.9.0 source tag.
4. Sign in with an organisation membership and select an active TEST or LIVE_LIKE environment.
5. Verify `/operations` and the permanent lost-response journey before using the workspace.

The operations API is additive under `/api/admin/v1`. It uses session authentication, signed
filter-bound cursors, and organisation/environment predicates. It never returns credential
digests, encrypted secrets, raw webhook bytes, cookies, headers, or stored response bytes.
The merchant `/api/v1` and generated Python SDK remain backward compatible.
