# Upgrade to v0.8.0

Apply v0.8.0 over a green v0.7.0 database, then run all normal Alembic upgrades.

RelayPay migration `0012_observability` adds bounded `request_logs`, durable hourly
`usage_rollups`, and the composite payment-list index
`ix_payment_intents_scope_created_id`. Provider migration `0003_slow_fault` adds the synthetic
`SLOW_RESPONSE` test directive. Existing financial, integration, and immutable evidence rows are
not rewritten; the upgrade proof verifies preserved row counts and empty operations tables.

Observability remains opt-in. To run the local proof:

```bash
OBSERVABILITY_ENABLED=true docker compose --profile observability up --build
```

Prometheus is available at `http://localhost:9090` and the read-only anonymous local Grafana
viewer at `http://localhost:3001`. Do not expose either development endpoint publicly.

No `/api/v1` operation, response, cursor, error, or idempotent replay contract is removed or
changed. No deployment or hosting change is part of this release.
