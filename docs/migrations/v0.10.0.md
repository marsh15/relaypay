# RelayPay v0.10.0 migration

v0.10.0 adds no PostgreSQL schema migration. Upgrade the application and optionally build the
edge Worker with `make edge-check`.

Direct-origin behavior remains the local default. Operators enabling the edge boundary must set
the same secret in the Worker's `ORIGIN_SIGNING_SECRET` secret and the origin's
`EDGE_ORIGIN_SIGNING_SECRET`, then set `EDGE_ORIGIN_SIGNATURE_REQUIRED=true`. Restrict the origin
network path before enabling enforcement. Existing `/api/v1` response bytes and financial data
are unchanged.
