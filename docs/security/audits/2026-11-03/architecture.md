Merchant API keys may mutate scoped TEST or LIVE_LIKE customer/payment resources; operator sessions carry organisation membership roles. Platform admins are distinct from organisation admins. Protect tenant records, credentials, approval authority, synthetic financial state, signed event integrity, and operator resources.
