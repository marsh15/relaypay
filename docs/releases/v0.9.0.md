# RelayPay v0.9.0

RelayPay v0.9.0 turns the Scenario Lab into a tenant- and environment-scoped operations
workspace while preserving the payment core and frozen merchant API.

## Included

- shared signed-cursor list and sanitized detail patterns for merchant accounts, settlements,
  beneficiaries, payouts, connectors, inbound and outbound webhooks, dead letters,
  reconciliation, API keys, audits, usage, and operational request metrics;
- strict organisation/environment predicates on every operational query;
- masked bank-account references and explicit exclusion of credentials and raw request bytes;
- keyboard-native navigation, semantic tables, visible focus, reduced-motion support, loading,
  empty, and error states;
- responsive layouts down to 320 px and automated Playwright/axe coverage across every view.

## Compatibility and safety

All new endpoints are session-authenticated `/api/admin/v1` reads. `/api/v1`, financial
journals, immutable evidence, and idempotent response bytes are unchanged. PostgreSQL remains
authoritative and the release performs no deployment or hosting.

**Synthetic data only. RelayPay is not a payment processor. Never submit real payment,
bank-account, identity, or customer data.**
