# RelayPay v0.5.0 — Reserved payouts and synthetic bank recovery

RelayPay v0.5.0 adds beneficiary references, payout reservations, numbered bank attempts, and
lookup-only recovery while preserving existing `/api/v1` payment contracts and immutable evidence.

> **Synthetic data only.** Never submit real bank, card, identity, customer, or regulated data.
> This release is not deployed or hosted.

## Added

- Environment-scoped synthetic beneficiaries and organisation-admin payout APIs.
- Merchant-locked reservations derived from append-only reservation history; payout creation
  cannot reserve more than positive payout-eligible balance and creates no journal.
- Numbered attempts with stable keys of `payout:{payout_id}:attempt:{n}`.
- A separately credentialed mock-bank database and service with deterministic lost-response,
  pending, and decline faults.
- Mutation-send evidence committed before network I/O. After any send, every recovery operation is
  lookup-only.
- Ambiguous outcomes retain the reservation. Verified declines release it. Explicit admin retry
  reacquires funds under lock and creates the next attempt; there is no automatic business retry.
- Verified success atomically consumes the reservation, posts one balanced payout journal, updates
  the immutable balance projection, emits one immutable event, and stores terminal response bytes.

## Compatibility and migration

M4 adds tables and expands journal/balance-transaction type constraints without rewriting
historical rows. Read the [v0.5.0 migration guide](../migrations/v0.5.0.md).

## Verification

CI starts from empty databases and also upgrades a representative v0.4 schema. The permanent M4
suite proves one bank effect under duplicate workers, lookup-only ambiguity recovery, reservation
retention/release/consumption, overspend prevention, and explicit numbered retry.

## Limitations

- INR and synthetic bank references only.
- Payout dispatch is batch-worker driven; no bank-network certification or real transfer rail.
- Ambiguous outcomes require lookup recovery and remain reserved if the bank never establishes a
  terminal outcome.
- No deployment, hosting, real funds, KYC, AML, fraud, fee, or chargeback handling is included.
