# RelayPay v0.11.0 — Shared agent runtime

RelayPay v0.11.0 adds a PostgreSQL-authoritative agent runtime and Redpanda-derived business-event
backbone while preserving the existing payment API and immutable financial evidence.

Highlights:

- transactional, lease-published outbox events with a fixed PII-free envelope and consumer dedupe;
- immutable workflow, prompt, pricing, and evaluation versions with durable runs and reclaimable steps;
- deterministic retries, token/cost ceilings, cancellation state, bounded artifacts, approvals, and DLQ;
- typed fake/OpenAI/Claude/Gemini provider boundary with safety-limited failover;
- tokenized evidence, injection delimiters, allowlisted tenant-injected read tools, and immutable traces;
- `OPERATIONS_ANALYST`/`APPROVER` roles plus tenant-scoped queue and run-trace console views.

This is synthetic INR portfolio software. It handles no real money, customer data, banking data, or
live submission. No hosting or deployment is part of this release. Redpanda, Redis, and Celery are not
business authorities; PostgreSQL remains authoritative.
