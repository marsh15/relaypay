# RelayPay v0.12.0 — Dispute Response Agent

RelayPay v0.12.0 adds a human-controlled, synthetic dispute response workflow on the shared agent
runtime while preserving `/api/v1`, PostgreSQL authority, and all earlier lost-response gates.

Highlights:

- deterministic `dispute.created.v1` case intake for six bounded reason codes;
- allowlisted evidence selection with explicit missing evidence and snapshot-bound citations;
- immutable agent/analyst draft versions and transactional audit events;
- deterministic signed ZIP packages with canonical manifests and per-file SHA-256 digests;
- maker-checker approval bound to exact package bytes, with edit-time invalidation;
- send-before-network submission and status-only ambiguous recovery with one external effect;
- analyst console for review, revision, approval, exact download, and submission;
- fixed 30-case evaluation plus upgrade, isolation, self-approval, and byte-stability gates.

This is synthetic INR portfolio software. It handles no real money, identity, customer, banking, or
card-network data. The dispute network is a deterministic mock. No deployment or hosting is included,
and the workflow intentionally stops at `SUBMITTED`.
